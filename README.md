# 👑 Reino da Tabuada

Jogo educativo para crianças aprenderem as tabuadas do 2 ao 10.
Funciona direto no navegador (computador, tablet e celular), sem cadastro e sem propaganda.

## Recursos
- Modo Aprender, com explicações, dicas e leitura em voz alta
- 9 mundos de aventura (um por tabuada) com sistema de estrelas
- Perguntas aleatórias com reforço inteligente dos erros
- Desafio diário e desafio contra o tempo com recordes por jogador
- Grande Desafio Final para conquistar o título de Mestre da Tabuada
- Progresso salvo automaticamente no navegador

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub (por exemplo `reino-da-tabuada`).
2. Envie os arquivos desta pasta (`index.html`, `README.md` e `.nojekyll`).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
5. Após cerca de 1 minuto, o jogo ficará em `https://SEU-USUARIO.github.io/reino-da-tabuada/`.

## Rodar no computador
Abra o `index.html` no navegador, ou rode um servidor local:

```
python -m http.server 8000
```

e acesse `http://localhost:8000`.
